# Bounced

A pixel-art detective game set in the winter of 1963. You work at the Bureau of Cheque Fraud in Nassau County, New York. Each day, returned cheques arrive by envelope. Inspect them with a light, a UV pen and a loupe, compare them with the bank's records and the cheque guide, and mark what's wrong.

## Play

Open `index.html` in any web browser, or play online through GitHub Pages.

## Controls

- **Mouse:** click the envelope, drag the cheque, click checklist rows to mark flaws
- **1 / 2 / 3:** inspection light, UV pen, loupe
- **B:** cheque guide
- **Enter:** open the envelope, or file the case
- **Esc / right-click:** put the tool down
